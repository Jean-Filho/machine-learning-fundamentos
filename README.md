Machine Learning

Repositório de estudos e implementações práticas de algoritmos de Machine Learning com Python e scikit-learn, cobrindo classificação, regressão, clustering, ensemble methods, redução de dimensionalidade, redes neurais e processamento de texto.

📁 Conteúdo
Classificação
Introdução-KNN — Implementação do algoritmo K-Nearest Neighbors (KNN).
arvore-de-decisao.py — Classificação com árvore de decisão.
classificacao_svm.py — Classificação com Support Vector Machine (SVM).
regressao_logistica_diabetes — Regressão logística aplicada a um dataset de diabetes.
random_forest_gradient_boosting.py — Ensemble methods: Random Forest e Gradient Boosting.
Regressão
Regressão-Linear.py — Implementação de regressão linear.
Clustering
K-means — Agrupamento de dados com K-means.
Redução de dimensionalidade
pca_reducao_dimensionalidade.py — Principal Component Analysis (PCA) aplicado a um dataset (California Housing).
Redes Neurais
Rede_Neural_Artificial.py — Implementação de rede neural artificial.
RedesNeurais.py — Estudos complementares sobre redes neurais.
Pré-processamento e dados
preprocessamento_dataset_frutas — Pré-processamento de um dataset de frutas.
analise_frutas — Análise exploratória do dataset de frutas.
processamento_texto.py — Processamento de texto (NLP básico).
Avaliação de modelos
metricas_avaliacao_ml.py — Métricas de avaliação de modelos de Machine Learning (acurácia, precisão, recall, F1-score, etc).

🛠️ Tecnologias
Python
scikit-learn
matplotlib

📌 Objetivo

Este repositório reúne exercícios e implementações desenvolvidos durante os estudos de Machine Learning, servindo como material de consulta e portfólio.
